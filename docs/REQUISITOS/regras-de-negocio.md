# Regras de Negócio (RN)

* **RN01:** Podem existir agendamentos no mesmo horário, desde que sejam para profissionais diferentes.
* **RN02:** Um profissional não pode possuir dois agendamentos no mesmo horário.
* **RN03:** Todo agendamento deve estar vinculado a um cliente, serviço, profissional, data e horário.
* **RN04:** Horários bloqueados não podem receber novos agendamentos.
* **RN05:** Apenas administradores e profissionais autorizados podem gerenciar os horários conforme seu perfil de acesso.
* **RN06:** Um horário bloqueado deve permanecer indisponível para novos agendamentos até que seja liberado.
* **RN07:** Um agendamento cancelado libera o horário do profissional.
* **RN08:** Apenas usuários autorizados podem acessar as funções administrativas.
