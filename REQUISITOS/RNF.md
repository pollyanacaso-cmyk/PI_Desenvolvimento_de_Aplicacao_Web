# Requisitos Não Funcionais (RNF)

* **RNF01:** O sistema deve possuir uma interface simples, intuitiva e fácil de utilizar.
* **RNF02:** O site deve ser responsivo e funcionar em computadores, tablets e celulares.
* **RNF03:** O sistema deve garantir a segurança dos dados dos usuários.
* **RNF04:** O sistema deve apresentar bom desempenho e tempo de resposta adequado.
* **RNF05:** O sistema deve estar disponível pela internet por meio de computação em nuvem.
* **RNF06:** O sistema deve funcionar nos principais navegadores atuais.
* **RNF07:** O código deve ser organizado e de fácil manutenção.
* **RNF08:** O banco de dados deve garantir a integridade e consistência das informações.
