# Regras de Negócio (RN)

* **RN01:** Podem existir agendamentos no mesmo horário, desde que sejam para profissionais diferentes.
* **RN02:** Um profissional não pode possuir dois agendamentos no mesmo horário.
* **RN03:** Todo agendamento deve estar vinculado a um cliente, serviço, profissional, data e horário.
* **RN04:** Horários bloqueados pelo administrador não podem receber novos agendamentos.
* **RN05:** Apenas administradores podem cadastrar produtos e bloquear ou liberar horários dos profissionais.
* **RN06:** Um horário bloqueado deve permanecer indisponível para novos agendamentos até que seja liberado pelo administrador.
* **RN07:** Um produto só pode ser vendido quando houver estoque disponível.
* **RN08:** Após uma venda, a quantidade do produto deve ser atualizada no estoque.
* **RN09:** Um agendamento cancelado libera o horário do profissional.
* **RN10:** Apenas usuários autorizados podem acessar as funções administrativas.
